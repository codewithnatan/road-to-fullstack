# 🚀 JavaScript Modern Basics

This repository contains my practical foundations in modern JavaScript (ES6+). It serves as a solid stepping stone for my journey toward becoming a Frontend Developer and prepares me for building my upcoming Vue.js 3 application.

## 💻  What is inside this module?
Every file in the `src/` directory explores a core concept of modern development:

* **01_variables.js**: Safe data handling using modern `let` and `const` declarations.
* **02_datatypes.js**: Structuring real-world data inside complex Objects and Arrays.
* **03_conditions.js**: Handling logical workflows using `if-else` statements and logical operators (`&&`).
* **04_functions.js**: Writing clean, resuable code using **Arrow Functions** and Template Literals.
* **05_fetch.js**: Asynchronously loading live data via the **Fetch API** (the foundational mechanic to later connect with the WordPress REST API).
